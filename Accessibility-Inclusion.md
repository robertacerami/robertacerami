# Accessibility (a11y) Commitment

Software should be usable by everyone. I integrate accessibility into the development lifecycle from the start.

### ♿ Implementation Checklist
* **Semantic HTML:** Strict use of landmark elements (`<main>`, `<nav>`, `<section>`) and proper heading hierarchy.
* **Keyboard Navigation:** Ensuring all interactive elements are focusable and have visible focus indicators.
* **ARIA Patterns:** Using ARIA labels and roles only when native HTML is insufficient, following WAI-ARIA best practices.
* **Color & Contrast:** Maintaining WCAG 2.1 AA/AAA compliance for text contrast and avoiding color-only UI cues.

### 🛠 Testing Tools
My workflow includes automated testing (axe-core, Lighthouse) and manual verification using screen readers (NVDA/VoiceOver).
