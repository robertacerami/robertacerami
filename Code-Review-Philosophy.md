# Code Review & Mentorship Philosophy

As a Senior Engineer, I view code reviews as a tool for knowledge sharing and maintaining system integrity, not just bug hunting.

### 🔍 What I Look For
* **Maintainability:** Is the code self-documenting? Will a junior developer understand this in 6 months?
* **Security:** Are there exposed API keys? Is user input properly sanitized to prevent XSS?
* **Scalability:** Does this solution work for 10 users? Will it work for 10 million?
* **Consistency:** Adherence to the team's style guide and architectural patterns (DRY vs. AHA).

### 🌱 Mentorship
I prioritize constructive feedback that empowers developers, fostering a culture of psychological safety and technical excellence.
